## 项目介绍

[Langflow](https://github.com/langflow-ai/langflow) 是一款强大的工具，用于构建和部署 AI 驱动的代理和工作流。它为开发者提供可视化的创作体验以及内置的 API 和 MCP 服务器，将每个工作流转化为可集成到基于任何框架或技术栈构建的应用程序中的工具。Langflow 内置了丰富的功能，支持所有主流的 LLM、矢量数据库以及不断增长的 AI 工具库。

### **核心功能：**

- **‌可视化构建：** 提供直观的拖拽式界面，用户可以将 LLM、提示词模板、向量数据库、工具等组件拖拽到画布上，并像连接电路一样将它们组合起来，构建复杂的应用流程。‌
- **‌快速迭代测试：** 内置交互式聊天窗口，用户在构建流程的同时可以立即进行测试和调试，极大地提升了开发效率。提供实时预览和测试功能，支持可交互测试链路，快速验证逻辑和输出
- **一键部署与集成：** 构建完成的应用流可以一键部署为 API 端点，方便集成到现有的应用程序中。支持通过 API 调用已部署的应用

本项目提供的开源镜像商品 [**Langflow工具**]() ，已预先安装Langflow工具及其相关运行环境，并提供部署模板。快来参照使用指南，轻松开启“开箱即用”的高效体验吧。

> **系统要求如下：**
>
> - CPU: 2GHz 或更高
> - RAM: 4GB 或更大
> - Disk: 至少 40GB
