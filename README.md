## Project Introduction

[Langflow](https://github.com/langflow-ai/langflow) is a powerful tool for building and deploying AI-powered agents and workflows. It provides developers with both a visual authoring experience and built-in API and MCP servers that turn every workflow into a tool that can be integrated into applications built on any framework or stack. Langflow comes with batteries included and supports all major LLMs, vector databases and a growing library of AI tools.

### **Core Features:**

- **Visual Construction**:Provides an intuitive drag and drop interface where users can drag LLM, prompt word templates, vector databases, tools, and other components onto the canvas and combine them like connecting circuits to build complex application workflows. ‌

- **Rapid iteration testing**:Built in interactive chat window, users can immediately test and debug while building the process, greatly improving development efficiency. Provide real-time preview and testing functions, support interactive testing links, quickly verify logic and output

- **One click deployment and integration**:The completed application flow can be deployed as an API endpoint with just one click, making it easy to integrate into existing applications. Support calling deployed applications through APIs

    

The open - source image product [**Langflow tool**]() provided by this project has Langflow tool and its related runtime environment pre - installed and provides deployment templates. Come and refer to the usage guide to easily start an "out - of - the - box" and efficient experience!

> **System requirements are as follows:**
>
> - CPU: 2GHz or higher
> - RAM: 4GB or larger
> - Disk: At least 40GB
